A modern, responsive web portal for job seekers to browse listings, apply for jobs, and for employers to post job opportunities.

Features
Browse Jobs: Search job listings by category, location, and skills.

Job Application: Apply directly to jobs with uploaded resumes.

Employer Dashboard: Post jobs, manage listings, and view applications.

Responsive Design: Fully mobile-optimized.

Smooth Animations: Interactive UI with animations.

Technologies Used
Frontend: HTML, CSS, JavaScript, React.js

Backend: Node.js, Express (Optional)

Database: MongoDB (Optional)

Styling: TailwindCSS
